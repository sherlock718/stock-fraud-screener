# Feature Registry

All features used in the multi-factor stock screener, organized by factor group.

## Factor Groups

| Group | Description | Source Step |
|-------|-------------|-------------|
| Value | Price-to-fundamentals ratios | step5_compute_features |
| Quality | Profitability, balance sheet health | step5_compute_features |
| Momentum | Price/earnings momentum signals | step5_compute_features |
| Growth | Revenue/earnings growth rates | step5_compute_features |
| Fraud Risk | Accounting manipulation indicators | step5_compute_features + enrich_fraud_taxonomy |

## Selection Pipeline

Features pass through a 4-stage selection pipeline (see `research/feature_selection_engine.py`):

1. **PSI filter** (threshold: 0.25) — removes features with unstable distributions
2. **IC screen** (|mean IC| >= 0.02, BH FDR q<0.05) — keeps predictive features
3. **ICIR rank** (top 60) — prioritizes signal-to-noise
4. **Spearman dedup** (|r| > 0.85) — removes near-duplicates
